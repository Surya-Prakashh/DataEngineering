⭐️ MalwareScope — Phase 3 Data Architecture Technical Report

What Phase 3 Does

Phase 3 establishes the **Data Architecture & Schema Design** foundation for MalwareScope, delivering four core capabilities:

1. Identification of OLTP/OLAP Components (5 pts) — Clear mapping of the Medallion Architecture (Bronze raw ingestion, Silver 3NF operational storage, Gold dimensional analytics) and system comparison matrix.

2. Relational Schema Design (5 pts) — Modeled a Third Normal Form (3NF) relational database for operational transactional integrity (`devices`, `scan_logs`, `malware_families`) with primary/foreign keys and DDLs.

3. Star & Snowflake Schema Design (5 pts) — Designed a high-speed analytical data warehouse centered around `fact_malware_detections` surrounded by 4 core dimension tables (`dim_family`, `dim_device`, `dim_time`, `dim_engine`) and normalized snowflake sub-dimensions.

4. Data Cube Design & Analytical Queries (5 pts) — Built an interactive 3D OLAP Data Cube supporting Slice, Dice, Roll-up, and Drill-down operations, alongside advanced SQL analytical queries (`GROUP BY CUBE`, `ROLLUP`, and Window Function `RANK() OVER()`).
